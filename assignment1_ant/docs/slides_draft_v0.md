## 2. 문제 — 왜 처음 보는 지형에서 무너지는가

- 과제: Isaac-Ant-v0 정책이 **지형 형태·마찰만 바뀐 처음 보는 환경**에서도 걷게 만들기
- **연구 문제: 평면에서 학습한 Ant는 왜 처음 보는 지형에서 무너지는가?**
- 관찰 1 — 성능 붕괴: baseline 공식 평면 134.90 ± 27.74 → 처음 보는 지형 12종 평균 16.3
- 관찰 2 — 실패 = 뒤집힘: 종료 높이 임계를 0.31 → 0.20으로 낮춰도 전진 거리 그대로 (59 m) → 이미 뒤집혀 누운 상태
- 조교 평가: 우리 태스크 설정으로 로드하고 지형만 교체 → **학습 환경 + 로봇(센서·물성) + 학습 방법**이 설계 대상 (구조 변경은 불가, 10.05 공지)

> 노트: 연구 문제를 먼저 던지고, 진단 실험 두 개(성능 붕괴, 뒤집힘)로 문제를 좁혔다는 점을 강조.
> 높이가 아니라 자세(뒤집힘)가 표적이라는 것이 이후 가설의 출발점.

## 3. 평가 설계 — 학습과 분리된 4단 평가

| 단계 | 지형 | 용도 |
|---|---|---|
| 분석용 | 12종 (평지·블록 6종·계단·파도·빙판·상자·레일) | 가설 비교 |
| 선택용 held-out | Boxes · Rails | 체크포인트 선택에만 |
| 보고용 held-out | SlopedGrid · Pyramids | 선택 뒤 보고만 |
| 잠금 테스트 | UnseenMix (학습 범위 밖 블록·피라미드·경사 위 블록·원기둥·평지) | 마지막 1회 (10.05) |

- 공식 명령 `play_one_episode.py --seed 24 --num_envs 100`, 원래 보상, 첫 에피소드 누적 reward (조교 지표와 동일)
- 학습 seed 2~4개 반복, 한 번에 한 요인만 바꾸는 비교, 선택 규칙("선택용 held-out 1위") 사전 고정

> 노트: 평가를 먼저 설계했다. 체크포인트를 고르는 지형과 결론을 말하는 지형을 분리해 "고른 지형에 맞춘 결과"를 막았다.
> 잠금 테스트는 최종 선택이 끝난 뒤 한 번만 돌렸다.

## 4. 접근 한눈에 — 가설 5개, 세 갈래

- 축 1 환경: **H1 경험 부족** (지형 다양화·커리큘럼) · **H2 자세 제약 부족** (자세 종료 CaT·외란·레벨별 마찰)
- 축 2 로봇: **H3 감각 부족** (발 접촉 센서 + 관측 히스토리) · **H4 접촉 물성** (발 외피 재질 마찰)
- 학습: **H5 좌우 대칭 경험** (거울 데이터 증강)
- 그림: `docs/figures/r2_ladder.png` — 변형별 12종 평균 (막대 = 학습 seed 평균, 점 = seed별)

> 노트: 사다리 그림 하나로 전체를 보여 준다. 왼쪽(환경)은 40점대에서 멈추고, 로봇을 바꾸면 70점대, 대칭 증강으로 90점대.
> 이후 슬라이드는 이 그림의 각 구간을 가설별로 설명.

## 5. 축 1 결과 — H1 지지 (커리큘럼은 기각, 지형 비중이 핵심) · H2 기각

| 실험 | 12종 평균 |
|---|---|
| baseline (평면) | 16.3 (n=1) |
| V1 지형 무작위 | 44.4 ± 1.0 (n=2) |
| V2 난이도 차선 커리큘럼 | 47.5 ± 0.6 (n=3) |
| A-noPromo (승급·강등 제거) | 46.8 ± 0.9 (n=2) |
| A-randDiff (난이도 정렬 제거) | 47.9 ± 0.5 (n=2) |
| V6′ 자세 제약 종료 CaT | 44.4 (n=1) |
| V10 외란 + 기울기 페널티 | 43.8 (n=1) |
| V11 레벨별 지면 마찰 | 37.5 (n=1) |

- H1: 지형을 경험시키면 16 → 47. 그러나 커리큘럼을 빼도 그대로 → **커리큘럼 효과 미미, 어떤 지형을 얼마나 경험하느냐가 핵심**
- H2: 자세를 제약하거나 흔들어도 모두 V2 이하 (평지 낙상률도 V2 66% 대비 V6′ 70% · V10 63%) → **기각**

> 노트: H2는 팀원 의견에서 출발한 가설인데 실험으로 기각됐다. 조심시키면 덜 걸을 뿐 뒤집힘은 줄지 않았다 → 원인은 정보·능력 쪽이라고 보고 축 2로.
> V6′·V10·V11은 seed 1개라 근거가 약하다는 점도 말한다.

## 6. 축 2 결과 — H3 지지 · H4 결합 시 지지: 로봇을 바꾸는 쪽이 컸다

| 실험 (모두 V2 지형 위, V1214B만 블록 70% 지형) | 12종 평균 |
|---|---|
| V2 (대조군) | 47.5 ± 0.6 (n=3) |
| V12 발 접촉 센서 + 히스토리 3 step + 정규화 | 53.1 ± 1.4 (n=2) |
| V14 발 외피 재질 μ0.4 | 56.0 ± 3.5 (n=2) |
| V1214 = V12 + V14 | 74.7 ± 1.5 (n=3) |
| V1214B = V1214 + 블록 70% 지형 | 78.3 ± 2.1 (n=4) |

- 따로는 +5.6 / +8.5, 함께는 +27.2 → 감각과 물성의 **상호작용**
- 감각 분해 (V1214 기준, n=1): 히스토리 제거 68.5, LSTM으로 대체 67.1 → **짧은 기억 + MLP**가 최선
- 환경 쪽 변경(40점대)보다 로봇 쪽 변경(70점대)이 컸다

> 노트: 센서는 물리를 바꾸지 않고 정책이 아는 정보만 늘린다. 외피는 발과 지면의 마찰을 바꾼다 (Python cfg만 수정, 물성치 변경 허용 공지에 따름).
> 둘을 합쳤을 때 합보다 크게 오른 것이 핵심 — 감각이 외피의 미끄러짐을 보정한다는 해석 (직접 검증은 안 함).

## 7. 외피 마찰 sweep — H4: 마찰에는 내부 최적이 있다

- 그림: `docs/figures/r2_mu_sweep.png`
- V1214R 위 μ sweep: 0.2 **71.5 (n=1)** / 0.3 **73.6 ± 3.6 (n=3)** / 0.4 **71.7 ± 7.2 (n=3)** / 0.6 **67.7 (n=1)**
  → 높으면 발이 걸려 뒤집히고, 낮으면 미끄러진다 (예측과 일치)
- **결론 철회 사례**: V1214B에서 seed 1개로 "μ0.4가 μ0.3보다 낫다" (79.4 vs 73.7)고 판단
  → 3 seed에서 μ0.4 78.3 ± 2.5 = μ0.3 78.3 ± 4.2 동률 → **철회**. 이후 결론은 seed 3개 이상에서만

> 노트: 진단에서 본 "마찰이 클수록 뒤집힘"이 가설의 출발점. 외피 마찰을 바꿔 보니 중간값이 가장 좋았다.
> seed 하나로 결론을 냈다가 뒤집힌 경험을 그대로 보여 주는 것이 실험 설계의 신뢰성.

## 8. 대칭 증강 V8 — H5 지지: 거울 경험으로 +12.9

- 아이디어: Ant 몸은 좌우 대칭 → PPO 업데이트 때 배치의 상태·행동을 좌우 거울로 뒤집어 추가 (rollout 1번으로 2배 경험, 파라미터 추가 없음; Mittal et al., ICRA 2024)
- 결과: **V8 91.2 ± 2.8 (n=4)** vs V1214B 78.3 ± 2.1 (n=4) — 4 seed 모두 V1214B 최고 seed보다 높음
- 거울 맵을 **시뮬레이션에서 검증**: env 1을 env 0의 거울 상태로 두고 거울 행동으로 같이 굴려 관측 비교 (240쌍, 모든 항 상관 +0.81~1.00)
- 발 반력(관절 wrench)은 좌표계 때문에 손으로 부호를 유도하다 틀림 → **상관으로 측정**해 맵 확정 (0.81~0.99)
- 그림: `docs/figures/r2_heatmap.png` — 지형별 reward, V8 행이 거의 모든 지형에서 가장 높음

> 노트: 이번 발표의 독창성 포인트. "왼발로 익힌 요령은 오른발도 안다"는 경험을 학습 데이터로 모델링.
> 추측 대신 측정으로 맵을 확정한 과정을 짧게.

## 9. 대칭 어블레이션 — 이득은 어디서 오는가

| 실험 | 12종 평균 | 대조군 대비 |
|---|---|---|
| V1214B (대조군) | 78.3 ± 2.1 (n=4) | |
| V8 거울 데이터 증강 | 91.2 ± 2.8 (n=4) | +12.9 |
| V8-ML "대칭으로 행동하라" 손실만 | 77.9 ± 1.1 (n=2) | −0.4 |
| V2Sym 기본 로봇 + 증강 (대조군 V2 47.5) | 50.2 ± 2.7 (n=3) | +2.7 |

- 대칭을 강제하는 손실만으로는 효과 없음 → 이득은 **거울 데이터(경험)** 에서
- 감각·물성 변경이 없는 기본 로봇에서는 +2.7뿐 → **로봇 변경 위에서만 크게 작동** (+12.9 vs +2.7)

> 노트: 대조 실험 두 개로 "대칭인 정책"과 "거울 경험"을 분리했다.
> 감각이 풍부할 때 거울 데이터가 크게 작동한다는 상호작용은 해석 단계 (직접 검증은 안 함).

## 12. 한계와 배운 것

- **뒤집힘 자체는 남았다**: 평지 낙상률 V2 66.3% / V8 65.8% → 향상은 넘어지기 전까지 더 멀리 걷는 데서 왔다
- 평가 지형 폭(32 m)이 빠른 정책에는 좁다: 약 27% 이탈 → 지형 안 로봇만 봐도 결론은 같지만 넓은 지형 재평가는 못 함
- 높이 스캔(RayCaster) 미사용: 정적 메시 1개만 지원 → 조교 지형이 박스 prim이면 에러 → 발 접촉 센서 + 히스토리로 대체
- seed 1개 결론은 뒤집힐 수 있다 (μ 철회) → 결론은 seed 3개 이상. V6′·V10·V11은 seed 1개라 근거가 약함
- 실험 운영: 백그라운드 실행 알림 누락으로 GPU가 놀았던 일 → 실행 도구·절대 경로로 통일

> 노트: 한계를 숨기지 않는다. 특히 "뒤집힘은 그대로"는 다음 연구 문제로 제시.
> 마지막 문장: "처음 보는 지형에서 걷게 만든 건 조심이 아니라 감각과 경험이었다."
