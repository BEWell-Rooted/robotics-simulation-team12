# 추가 고려 사항 검토 (10.05) — 팀 리뷰 사전 읽기용 (~30분)

조교 추가 공지: (1) 로봇은 **센서 추가 + 소프트웨어 제어 요소(PD gain, 토크 한계 등)** 만 변경 가능, 하드웨어 구조 변경 불가.
USD 파일은 센서 추가 목적으로만 수정 허용. (2) 평가는 **연구 문제 → 가설 → 실험 설계·분석**의 논리가 핵심, reward 순위만으로 평가하지 않음.
(3) 독창성 = 팀의 경험을 가설로 만들어 실험으로 입증하는 것 (예: 보행 우선순위를 보상·학습 목표로 모델링).

## 1. 규정 점검 — 우리가 바꾼 것 하나씩

**결론: V14(외피 재질)는 빼는 것이 안전.** 현재 최종 모델 V8(= V1214B + 대칭)은 V14를 포함하므로 **교체 후보가 필요**.

### 대응

- 외피 없는 대안 V8N(= V8 − 외피)·V12B를 13:29에 학습 시작했으나 **검토 시간 부족으로 중단** (태스크 등록만 남김: `Isaac-Ant-Rough-V8N-v0`, `-V12B-v0`)
- 외피 없는 기존 수치: V12 53.1 (V2 지형) / V12R 55.9. 외피가 +21 (V12 53.1 → V1214 74.7)
- **조교 확인이 가장 확실**. 질문안: "로봇 링크(발 포함)의 충돌 마찰계수를 Python cfg에서 바꾸는 것(USD 파일 수정 없음)도 허용되는 소프트웨어적 변경에 포함되나요? 마찰 결합 방식(combine mode) 지정도 괜찮을까요?"
- 판단 기준 정리: 센서 = 정책이 아는 정보만 늘림 (물리 불변, 명시 허용) / 제어 = 힘을 내는 방식 / **외피 마찰 = 지면과의 물리 상호작용을 바꿈** → 공지 취지("몸은 그대로")에 비추면 애매
- 이전 조교 답변("센서나 물성치를 바꿔도 된다")과 이번 공지("제어 요소만")가 충돌 → 문의 근거

### 팀이 정할 것

1. 외피(V14) 처리: 조교 문의 → 허용이면 V8 그대로 제출 / 불허면 외피 없는 모델이 필요 (재학습 필요, 시간 고려)
2. 외피 실험을 발표에서 어떻게 다룰지 — 제안: "규정 확인 전 수행한 탐색 실험, 최종 모델에서는 제외" + 진단 근거로만 사용
   (마찰이 높을수록 뒤집힘 ↑ 라는 **환경 쪽 분석**은 규정과 무관하게 유효)
3. 추가 학습은 하지 않음 (10.05 결정). PD gain / 토크 한계 실험도 미착수

## 2. 발표 구조 재편 — "연구 문제 → 가설 → 검증"

지금 `report_material.md`는 "무엇을 바꿨나" 순서. 조교 기준에 맞춰 **가설 단위**로 다시 묶는 것을 제안한다. 기존 실험으로 대부분 채워진다.

**연구 문제**: 평면에서 학습한 Ant는 왜 처음 보는 지형에서 무너지는가?
- 관찰: baseline 평면 134.9 → 자체 unseen 12종 평균 16.3. 실패의 대부분이 **뒤집힘** (낙상 = 뒤집힘)

| 가설 | 예측 | 실험 (통제) | 결과 | 판정 |
|---|---|---|---|---|
| H0 종료 임계가 너무 엄격해서 "넘어진 것처럼" 보인다 | 임계를 낮추면 거리 회복 | 종료 높이 sweep | 거리 회복 없음 | ❌ 기각 |
| H1 학습 분포가 평면뿐이다 | 지형 다양화로 향상 | V1 무작위 / V2 차선 | 16 → 44 / 47.5 | ✅ |
| H1a 그중 핵심은 커리큘럼(쉬운→어려운)이다 | 커리큘럼 제거 시 하락 | A-noPromo, A-randDiff (승급·정렬 제거) | 46.8 ≈ 47.9 ≈ 47.5 | ❌ 기각 → 핵심은 **지형 비중** (V2R·V1214B) |
| H2 넘어지는 건 자세 제약이 없어서다 (팀원 의견) | 자세 페널티·종료로 향상 | V4 페널티, V6′ CaT, V10 외란+기울기 | 38.9 / 44.4 / 43.8 (V2 47.5보다 낮음) | ❌ 기각 — 조심하게 만들면 덜 걷는다 |
| H3 정책이 발밑을 "모른다" (감각 부족) | 접촉 센서 + 최근 기억으로 향상 | V12, 분해: 히스토리 제거·LSTM 대체 | 47.5 → 53.1, 히스토리 제거 −8, LSTM 더 낮음 | ✅ 짧은 기억 + 접촉 |
| H4 좌우 대칭 상황을 절반만 경험한다 (데이터 비효율) | 거울 데이터로 향상, 대칭 강제만으론 X | V8 증강 / V8-ML 손실만 / V2Sym 감각 없이 | +13 / +0 / +2.7 | ✅ **감각이 있을 때만** 큰 효과 |

- H2가 **반증된 가설**이라는 점이 오히려 연구적으로 강함 (팀원 코멘트에서 출발 → 실험으로 기각 → 다음 가설로)

## 3. 독창성 — 팀 경험을 가설로

"처음 보는 길을 걸을 때 우리는 어떻게 하는가?"
1. **발바닥으로 먼저 확인한다** → 발 접촉 센서 (H3)
2. **방금 디딘 몇 걸음을 기억한다** → 3 step 관측 히스토리 (H3, 긴 기억(LSTM)은 오히려 손해)
3. **왼발로 익힌 요령은 오른발도 안다** → 좌우 대칭 데이터 증강 (H4) — 몸의 대칭을 학습 데이터로 모델링
4. "넘어지지 않게 조심하라"는 직관은 **틀렸다** (H2) — 조심만 시키면 덜 걷는다

독창성 포인트(기술): 대칭 맵을 손으로 유도하다 발 반력 부호에서 막혀 **시뮬레이션에서 거울 상태 쌍을 굴려 측정**으로 확정 (상관 0.81~1.00).
