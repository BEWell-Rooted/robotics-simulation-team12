# 추가 고려 사항 검토 (10.05) — 팀 리뷰 사전 읽기용 (~30분)

조교 추가 공지: (1) 로봇은 **센서 추가 + 소프트웨어 제어 요소(PD gain, 토크 한계 등)** 만 변경 가능, 하드웨어 구조 변경 불가.
USD 파일은 센서 추가 목적으로만 수정 허용. (2) 평가는 **연구 문제 → 가설 → 실험 설계·분석**의 논리가 핵심, reward 순위만으로 평가하지 않음.
(3) 독창성 = 팀의 경험을 가설로 만들어 실험으로 입증하는 것 (예: 보행 우선순위를 보상·학습 목표로 모델링).

## 3. 독창성 — 팀 경험을 가설로

"처음 보는 길을 걸을 때 우리는 어떻게 하는가?"
1. **발바닥으로 먼저 확인한다** → 발 접촉 센서 (H3)
2. **방금 디딘 몇 걸음을 기억한다** → 3 step 관측 히스토리 (H3, 긴 기억(LSTM)은 오히려 손해)
3. **왼발로 익힌 요령은 오른발도 안다** → 좌우 대칭 데이터 증강 (H5) — 몸의 대칭을 학습 데이터로 모델링
4. "넘어지지 않게 조심하라"는 직관은 **틀렸다** (H2) — 조심만 시키면 덜 걷는다

독창성 포인트(기술): 대칭 맵을 손으로 유도하다 발 반력 부호에서 막혀 **시뮬레이션에서 거울 상태 쌍을 굴려 측정**으로 확정 (상관 0.81~1.00).
