# 발표 재료 (5분 PPT용) — 과제 1: 처음 보는 지형에서도 걷는 Ant

- 구성: **연구 문제 → 관찰 → 가설 → 실험 설계 → 가설별 검증 → 최종 검증 → 한계** (조교 평가 기준 "연구적인 실험 설계와 결과 분석")
- 갱신: 2026.10.05 (월) — 가설 중심으로 재구성. 근거: `log_0929.md` ~ `log_1005.md`, `results/summary_round2.md`, `docs/figures/`
- 수치: 자체 unseen 평가 12종 평균 reward (원래 Isaac-Ant-v0 보상, eval seed 24·25 × 256 envs), **학습 seed 평균 ± 표준편차** (n = seed 수)
- 표기: ✅ 지지 / ❌ 기각 / △ 부분 지지 · "해석"이라고 적은 것은 실험으로 직접 검증하지 않은 설명

---

## 1. 연구 문제

> **평면에서 학습한 Ant는 왜 처음 보는 지형에서 무너지는가? 그리고 무엇을 바꾸면 처음 보는 지형에서도 걷는가?**

## 2. 관찰 — 문제를 쪼개기 (진단 실험)

baseline(Isaac-Ant-v0 기본 학습)을 자세히 들여다본 결과 세 가지를 관찰했다.

| | 관찰 | 근거 (실험) |
|---|---|---|
| O1 | **성능 붕괴**: 평면 134.9 → 처음 보는 지형 12종 평균 16.3 | 공식 조건 평면 vs 자체 평가 12종 |
| O2 | **실패 = 뒤집힘**: 종료 높이 임계를 0.31 → 0.20으로 낮춰도 전진 거리 불변 (59 m), 종료 순간 거의 전부 기울기 up-proj < 0.7 | 종료 임계 sweep (`figures/diag_threshold.png`) |
| O3 | **평면이 아닌 표면 + 충분한 마찰에서만 뒤집힘**: 해석적 평면 낙상 7% vs 박스 도형 평지 39% ≈ 메시 평지 47% / 메시에서 μ0.2 → 0.5로 낙상 5% → 43% | 같은 셀 배열의 박스 prim vs 메시 쌍둥이, 마찰 격자 (`figures/diag_surface.png`, `diag_mu_grid.png`) |

- O2로 "높이 마진이 부족해서 넘어진 것처럼 보인다"는 가설(H0)은 **기각** → 표적은 높이가 아니라 **자세(뒤집힘)**
- O3: 학습한 평면(해석적 평면)이 예외적으로 관대했을 뿐 → 조교 지형이 박스 도형이든 메시든 같은 문제가 생긴다 (평가 설계의 근거도 됨)

## 3. 가설 — 관찰에서 원인 후보 5개

| 가설 | 원인 후보 | 예측 (맞다면) | 출발점 |
|---|---|---|---|
| **H1 경험 부족** | 평면만 경험해서 다른 지형에서의 대처를 배우지 못했다 | 다양한 지형으로 학습하면 향상 | O1 |
| **H2 자세 제약 부족** | 넘어지지 않도록 하는 학습 신호가 없다 | 자세 페널티·자세 종료·외란을 주면 뒤집힘 ↓ | O2, 팀원 의견 |
| **H3 감각 부족** | 정책이 발이 땅에 닿았는지, 방금 무슨 일이 있었는지 모른다 | 발 접촉 센서 + 짧은 기억을 주면 향상 | O2 (같은 관측으로 평면과 블록을 구분 못 함) |
| **H4 접촉 물성** | 마찰이 크면 발이 걸려 몸이 뒤집힌다 | 발-지면 마찰을 낮추면 향상, 너무 낮으면 미끄러짐 | O3 |
| **H5 경험의 비효율** | 몸은 좌우 대칭인데 정책은 왼쪽·오른쪽 상황을 따로 배워야 한다 | 거울 데이터를 주면 같은 학습량으로 향상 | 학습 효율 |

## 4. 실험 설계 — 공통 원칙 (타당성)

1. **평가부터 설계, 학습과 분리된 3단 평가**
   - 분석용 12종 (평지·블록 6종·계단·파도·빙판·상자·레일): 가설 비교에만 사용
   - 선택용 held-out (Boxes, Rails): 체크포인트 선택에만 사용 / 보고용 held-out (SlopedGrid, Pyramids)
   - **잠금 테스트 `UnseenMix`** (학습 범위 밖 블록 h±0.13, 피라미드, 경사 위 블록, 원기둥, 평지): **마지막에 1회만**
2. **조교와 같은 지표**: 원래 Isaac-Ant-v0 보상, 첫 에피소드 누적 reward. 공식 수치는 `play_one_episode --seed 24 --num_envs 100`
3. **한 번에 한 요인만 바꾸는 통제 비교 + ablation**: 각 가설마다 "그 요인만 뺀/더한" 대조군
4. **학습 seed 반복** (2~4개) — seed 1개로 내린 결론은 뒤집힐 수 있음 (실제 사례: V1214B μ0.3을 seed 1개로 "열세"라 했다가 3 seed에서 동률 → 철회)
5. **예산 공정성**: baseline도 3000 iter 학습 → 16.6 ≈ 16.3 (1000 iter). 차이는 학습량이 아니라 조건에서 나온다
6. **선택 규칙 사전 고정**: "선택용 held-out 1위" → 최종 모델 선택에 사람의 판단이 들어가지 않게

그림: `figures/terrains/terrain_overview.png` (평가 지형), `figures/terrains/train_layouts.png` (학습 지형 배치)

## 5. 가설별 검증

### H1 경험 부족 → ✅ (단, 핵심은 커리큘럼이 아니라 지형 비중)

| 실험 | 12종 | 결론 |
|---|---|---|
| baseline (평면) | 16.3 | |
| V1 지형 무작위 (n=2) | 44.4 ± 1.0 | ✅ 다양한 지형 경험으로 +28 |
| V2 난이도 차선 커리큘럼 (n=3) | 47.5 ± 0.6 | |

- **H1a "핵심은 커리큘럼(쉬운 → 어려운)이다"** → ❌ 기각
  - 승급·강등 제거 A-noPromo 46.8 ± 0.9, 난이도 정렬 제거 A-randDiff 47.9 ± 0.5 ≈ V2 47.5
- **H1b "핵심은 어떤 지형을 얼마나 경험하느냐(비중)다"** → ✅
  - 배치만 섞은 V2R 42.0: 블록 49.3 → 41.7 ↓, 계단 7.0 → 34.0 ↑ → 비중이 바뀌면 강점이 바뀐다
  - 블록 70% 비중으로 다시 설계한 V1214B 78.3 ± 2.1 > V1214 74.7 (블록 강점) · V1214R 71.7 (계단 강점) → 교환관계 해소

### H2 자세 제약 부족 → ❌ 기각

| 실험 (모두 V2 위, 한 요인씩) | 12종 | 평지 낙상률 |
|---|---|---|
| V2 (대조군) | 47.5 | 66% |
| V4 자세 안정성 페널티 (n=2) | 38.9 | **93%** |
| V6′ 자세 제약 종료 CaT (n=1) | 44.4 | 70% |
| V10 외란 + 기울기 페널티 (n=1) | 43.8 | 63% |

- 예측("뒤집힘 ↓")과 반대: 성능은 모두 대조군 이하, 낙상률도 줄지 않음 (V4는 오히려 증가)
- 해석: 넘어지지 말라고 "조심"시키면 보폭·속도가 줄어 덜 걸을 뿐, 뒤집히는 상황 자체를 다루는 능력은 생기지 않는다 → **원인은 의지가 아니라 정보·능력** → H3로
- 같은 맥락: 학습 지면 마찰을 레벨별로 다양화(V11, 환경 쪽 마찰)도 37.5로 하락

### H3 감각 부족 → ✅ (짧은 기억 + 접촉)

| 실험 | 12종 | 결론 |
|---|---|---|
| V2 (대조군) | 47.5 | |
| V12 발 접촉 센서 + 관측 히스토리 3 step + 정규화 (n=2) | 53.1 ± 1.4 | ✅ +5.6, 평지 38.5 → 48.6 |
| 분해: V1214에서 히스토리 제거 (n=1) | 74.7 → 68.5 | 기억이 필요 |
| 분해: 히스토리 대신 LSTM (n=1) | 74.7 → 67.1 | 긴 기억은 오히려 손해 → **짧은 기억 + MLP** |

- 센서는 물리를 바꾸지 않고 정책이 받는 정보만 늘린다 (공지의 "센서 추가 허용" 범위)

### H4 접촉 물성 → △ 부분 지지 (블록에서 지지, 평지에서는 미끄러짐), 감각과 결합하면 ✅

| 실험 | 12종 | 블록 6종 | 평지 낙상률 |
|---|---|---|---|
| V2 (대조군) | 47.5 | 49.3 | 66% |
| V14 발 외피 재질 μ0.4 (combine "min") (n=2) | 56.0 ± 3.5 | **62.8** | **85%** ↑ |
| V12 + V14 = V1214 (n=3) | **74.7 ± 1.5** | 80.7 | 67% |

- 외피 마찰 sweep (V1214R 위): μ 0.2 71.5 / **0.3 73.6** / 0.4 71.7 / 0.6 67.7 → **내부 최적** — 예측("높으면 걸리고 낮으면 미끄러짐")과 일치 (`figures/r2_mu_sweep.png`)
- 외피만 바꾸면 블록에서는 좋아지지만 평지에서는 더 넘어진다 (미끄러짐)
- **감각 × 물성 상호작용**: V12 +5.6, V14 +8.5, 둘 다 +27.2 (> 합 14.1). 평지 낙상률도 85% → 67%로 복귀
  - 해석: 접촉 센서와 기억이 미끄러짐을 알아채 보정한다 (직접 검증은 안 함)
- 지면 마찰을 학습에서 다양화(V11)는 실패, 로봇 발 재질을 설계하는 쪽은 성공 → **환경을 바꾸기보다 로봇을 바꾸는 쪽이 효과적**
- 규정: Python cfg만 수정 (USD 파일 수정 없음), 지난 수업 물성치 변경 허용 공지에 따름. 조교가 지면 마찰을 바꿔도 유효 마찰의 상한을 로봇이 정한다는 점은 숨기지 않고 밝힘

### H5 경험의 비효율 (좌우 대칭) → ✅ (감각이 있을 때만 크게)

방법: PPO 업데이트 때 배치의 모든 상태·행동을 좌우 거울로 뒤집어 추가 (rollout 1번으로 2배 경험, 파라미터 추가 없음)

| 실험 (통제) | 12종 | 대조군 대비 |
|---|---|---|
| V1214B (대조군, n=4) | 78.3 ± 2.1 | |
| **V8 = V1214B + 거울 데이터 증강 (n=4)** | **91.2 ± 2.8** | **+12.9** (4 seed 모두 대조군 최고 seed보다 높음) |
| V8-ML = 증강 없이 "대칭으로 행동하라" 손실만 (n=2) | 77.9 ± 1.1 | −0.4 → 대칭 강제만으로는 효과 없음 |
| V2Sym = 감각·물성 없는 기본 로봇 + 증강 (n=3) | 50.2 ± 2.7 | V2 대비 +2.7 → 감각이 없으면 효과 작음 |

- 결론: 이득은 "대칭인 정책"이 아니라 **거울 경험(데이터)** 에서 나오고, **풍부한 감각(접촉·기억)이 있을 때** 크게 작동
- 지형별: 블록 80.8 → 96.7, 평지 69.8 → 86.7, 계단 57.9 → 71.5, 보고용 84.8 → 98.1
- **실험 타당성 확보 — 대칭 맵을 측정으로 검증**: env1을 env0의 거울 상태로 두고 거울 행동으로 같이 굴려 관측이 맞는지 확인 (240쌍, 상관 +0.81~1.00).
  발 반력(관절 wrench)은 좌표계 때문에 손으로 부호를 유도하다 틀려서 → **추측 대신 측정**으로 확정

## 6. 최종 검증 — 잠금 테스트 (처음 보는 환경, 1회)

- 최종 모델: 사전 규칙(선택용 held-out 1위)으로 **`v8_s44@2999`** (Boxes·Rails 111.5)
- `UnseenMix`, 공식 조건 (seed 24, 100 envs), 10.05 1회

| 모델 | 반영된 가설 | reward | 평균 step (960 = 완주) |
|---|---|---|---|
| baseline | — | 9.51 ± 7.52 | 761 |
| V2 | H1 | 46.70 ± 30.17 | 863 |
| V1214B | H1 + H3 + H4 | 100.19 ± 22.11 | 946 |
| **V8 (최종)** | H1 + H3 + H4 + H5 | **113.65 ± 29.03** | 938 |

- 자체 평가에서 본 순서가 처음 보는 잠금 테스트에서도 그대로 → 가설 검증 결과가 평가 지형에 과적합된 것이 아니다
- H5 효과: 자체 평가 +12.9 ↔ 잠금 테스트 +13.5 (재현)
- 제출 태스크 공식 평면: 174.73 ± 12.67 (baseline 134.90 ± 27.74) → 평면 성능도 손해 없음
- **타당성 점검 — 지형 밖 이탈**: 평가 지형은 160 m × 32 m (+ 바깥 평평한 border). 로봇은 목표 방향에서 조금씩 비스듬히 걷기 때문에
  잠금 테스트에서 V8·V1214B는 약 27%, V2 15%, baseline 3%의 로봇이 한때 지형 밖(border)으로 나간다 (V8은 10대가 지형 끝 x > 80 m까지 도달).
  지형 밖에 한 번도 나가지 않은 로봇만 비교해도 순서는 그대로: baseline 9.1 < V2 42.6 < V1214B 87.8 < **V8 104.6** (V8 − V1214B +16.8)
  → 이탈이 절대 수치는 부풀리지만 가설 비교 결론은 바꾸지 않는다 (`scripts/eval_task.py`의 off-terrain 기록, eval 스크립트 기준 수치)

## 7. 한계 — 무엇을 아직 설명하지 못했나

- **원래 실패 모드(O2 뒤집힘)는 남아 있다**: 평지 낙상률 V2 66% / V1214B 69% / V8 66%로 거의 그대로.
  향상은 "넘어지지 않게 된 것"보다 **넘어지기 전까지 더 멀리, 빠르게 걷게 된 것**에서 왔다 → 뒤집힘 자체를 줄이는 방법은 열린 문제
- 평가 지형 폭(32 m)·길이(160 m)가 빠른 정책에는 좁다: 약 27%가 지형 밖으로 이탈 → 지형을 더 넓고 길게 만든 재평가는 시간상 미실시
- V8의 잠금 테스트 표준편차가 큼 (29.0 vs V1214B 22.1): 빠르게 걷다 일부 넘어짐
- 일부 가설 실험은 seed 1개 (V6′, V10, V11, 분해 실험) → 근거가 약함, 발표에서 명시
- H4·H5의 "상호작용" 해석(감각이 미끄러짐을 보정 / 감각이 있어야 거울 데이터가 유효)은 가설 단계 — 직접 검증 안 함
- 외피 재질(combine "min")은 지면 마찰이 바뀌어도 유효 마찰 상한을 로봇이 정함 → 평가 조건에 대한 해석 여지

## 8. 독창성 — 팀의 보행 경험을 가설로

"처음 보는 길을 걸을 때 우리는 어떻게 하는가?"를 가설로 바꿔 검증했다.

| 우리의 경험 | 가설 | 실험 결과 |
|---|---|---|
| 넘어지지 않게 조심하면 되지 않을까? | H2 | ❌ 조심만 시키면 덜 걷는다 |
| 발바닥으로 땅을 먼저 느낀다, 방금 디딘 걸음을 기억한다 | H3 | ✅ 접촉 + 짧은 기억 (긴 기억은 손해) |
| 미끄러운 신발, 걸리는 신발이 있다 | H4 | △ 신발(외피)에도 최적 마찰이 있다 |
| 왼발로 익힌 요령은 오른발도 안다 | H5 | ✅ 거울 경험이 +13, 단 감각이 있을 때 |

- 기술적 독창성: 대칭 맵을 시뮬레이션 측정으로 검증 (5절 H5)
